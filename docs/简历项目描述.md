# FlowPilot 简历项目描述

**FlowPilot 材料企业采购申请自动填报 Agent｜个人独立项目，获业务方采纳**

技术栈：Python／FastAPI／Playwright／Pydantic／React／TypeScript／SQLite／SSE／WebMCP（实验）。

- 面向材料企业采购申请，独立搭建任务工作台和自建门户，将自然语言需求解析为部门、物品、数量、预算及用途等字段，自动填写并展示核对截图，人工确认后提交及验证回执。
- 使用 Playwright 执行页面工具和语义 DOM 两条路径，Pydantic 校验结构化字段及路径，逐字段检查填写结果；待确认状态保存检查点与内容摘要，恢复时重建浏览器并重填复验。
- 提交按任务唯一键复用回执，支持中断恢复与断线事件重放。100 条固定合成规则需求字段匹配 500/500，本地浏览器流程 12/12 通过；测试未调用真实模型，仅覆盖自建演示门户。

公开仓库是可复现演示版本，门户与申请数据均为合成内容，不含企业业务数据或生产配置。实际业务采纳事实与仓库中的模型效果评测口径分开说明。
